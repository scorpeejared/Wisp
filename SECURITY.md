# Security policy

Wisp has not had an independent security review. See the notice at the top of
the [README](README.md) and the "Known limitation" and "Not verified" sections
for what is and is not claimed.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private
vulnerability reporting on this repository (Security tab, "Report a
vulnerability") so it can be fixed before it is disclosed.

This is a personal project maintained on a best-effort basis, so there is no
response-time guarantee.
